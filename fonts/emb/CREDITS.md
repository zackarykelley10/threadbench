# Embroidery font credits

These satin lettering files were converted for Threadbench from the free Ink/Stitch embroidery fonts
(https://github.com/inkstitch/embroidery-fonts) using Ink/Stitch itself. Each font keeps its own license;
the license text is in the font's folder. Fonts under CC-BY-SA stay under CC-BY-SA 4.0, including these converted files.
